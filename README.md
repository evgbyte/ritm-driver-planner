# Ритм — планировщик смен водителя

Android-приложение для личного учёта смен, расходов на топливо и планирования рабочего графика.

## Что умеет приложение

- Записывать смены, поездки и доход.
- Учитывать расход и индивидуальную цену топлива.
- Рассчитывать ориентир чистого заработка после учтённого топлива.
- Показывать прогноз погоды и оценку спроса по времени.
- Сохранять профиль и журнал локально на устройстве.
- Работать без учётной записи и без входа в Яндекс Про.

Прогноз спроса — ориентир по публичной погоде, календарю событий и введённым сменам. Это не данные Яндекс Про и не гарантия дохода. Афиша автоматически поддерживается для Краснодара.


## Данные и внешние сервисы

Профиль автомобиля, доходы и журнал смен хранятся в локальном хранилище приложения. Для прогноза приложение подключается к Open-Meteo и источнику афиши Краснодара через сеть. Личные сведения о доходах и машине не включены в этот исходный проект или APK.

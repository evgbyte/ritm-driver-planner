# Ритм — планировщик смен водителя

Android-приложение для личного учёта смен, расходов на топливо и планирования рабочего графика.

## Что умеет приложение

- Записывать смены, поездки и доход.
- Учитывать расход и индивидуальную цену топлива.
- Рассчитывать ориентир чистого заработка после учтённого топлива.
- Показывать прогноз погоды и оценку спроса по времени.
- Сохранять профиль и журнал локально на устройстве.
- Работать без учётной записи и без входа в Яндекс Про.

Прогноз спроса — ориентир по публичной погоде, календарю событий и введённым сменам. Это не данные Яндекс Про и не гарантия дохода. Афиша автоматически поддерживается для Краснодара.

## Установка для друзей

Передайте APK `ritm-android.apk` из папки поставки. При первом запуске Android попросит разрешить установку из выбранного источника. Данные каждого водителя остаются на его устройстве.

## Сборка из исходников

Нужны JDK 17, Android SDK Platform 35, Android Gradle Plugin 8.13.2 и Gradle 8.13. Откройте папку проекта в Android Studio либо выполните:

```powershell
gradle assembleDebug
```

Debug-сборка появится в `app/build/outputs/apk/debug/app-debug.apk`. Для магазинов используйте отдельную release-сборку и собственный защищённый ключ подписи; не публикуйте файл ключа и пароли вместе с исходниками.

## Магазины приложений

Краткое описание, полное описание и список недостающих материалов находятся в `distribution/STORE_LISTING_RU.md`. Версия для друзей сейчас собрана с `targetSdk 34`. В проекте есть режим сборки магазина с `compileSdk 36` и `targetSdk 36`: `gradle bundleRelease -PstoreRelease=true`. Для него нужны Android SDK Platform 36, release-подпись и отдельная проверка перед подачей. RuStore принимает подписанные APK или AAB.

## Данные и внешние сервисы

Профиль автомобиля, доходы и журнал смен хранятся в локальном хранилище приложения. Для прогноза приложение подключается к Open-Meteo и источнику афиши Краснодара через сеть. Личные сведения о доходах и машине не включены в этот исходный проект или APK.
